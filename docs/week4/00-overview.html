SCOPE

이번 작업 5묶음

쿠폰을 중심으로 묶고, 동시성과 직결된 백로그를 흡수합니다. 자세한 내용은 01·02 문서에 있습니다.

A · 쿠폰 도메인 + 주문 통합발급(소유)·사용 도메인, 주문에 쿠폰 적용(검증·할인·USED·금액 스냅샷), 단일 트랜잭션 원자성.
B · 동시성 테스트 3종쿠폰 1회 / 재고 정확 / like_count 정확. Testcontainers MySQL.
C · 발행·지급·조회 API관리자 POST /api-admin/v1/coupons · 지급 .../{id}/grant · 사용자 GET /users/me/coupons. interfaces 레이어 신규.
D · CodeRabbit 백로그 18건이번 PR에 전부 포함. #6·#10·#11 은 위 동시성과 겹침.
E · 부가 트랙analyze-query 스킬(우리 스타일 고도화) + Technical Writing(락 선택 회고).
결정 사항 (고정)쿠폰 사용 = 낙관락(@Version) · 발급 = 관리자 발행·지급(셀프·선착순은 백로그) · 템플릿은 관리자 API 생성(기존 admin 인증 재사용). Coupon 에 name·createdBy 추가(minOrderAmount 는 Money), CouponType 은 식별만(표시명·분류 없음).
